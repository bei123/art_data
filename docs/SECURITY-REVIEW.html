Art Data Security Review

Revision: f337c40 + working tree · Date: 2026-06-29

No critical or high-severity vulnerability was confirmed. This was a single-agent review of deployed high-impact runtime families.

Findings

SEC-001 · Low · Plaintext passwords can enter registration logs

auth.js:181 logs the complete registration request body, including password, whenever public registration is enabled. Remove the log or strictly allowlist non-sensitive fields.

SEC-002 · Medium · WebView credentials are accepted in URL query parameters

routes/webview.js:22 reads authorization from the query string and forwards it. Edge/origin logs, browser history and diagnostics may retain the bearer token. Replace it with a short-lived opaque server-side handle.

Correctness defects

  • OpenAPI documents favorite creation as item_type/item_id, but the backend requires itemType/itemId.
  • Tests trigger a real OSS probe during module import; the parallel full suite reaches 212/214, while the focused security suite passes 30/30.
